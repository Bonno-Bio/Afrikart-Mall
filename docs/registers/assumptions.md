# Assumption Register

**Rule:** anything we believe but have not tested lives here, with the test that resolves it and the
date by which we will know. An assumption without a test is a wish.

**Owner:** CEO · **Reviewed:** weekly · **Update:** whenever a test closes.

Status key: `untested` · `testing` · `supported` · `refuted` · `inconclusive`
